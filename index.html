The 5 Tiers

Veil → Calamity

The tier comes from a formula, never a gut feel. As the score climbs, the portrait's silhouette, palette, and motifs decay along a canonical codex.

  1. T1

    Veil

    score < 1.0

    Translucent child-shadow, faint waver. A nascent codebase — the portrait reassures.

  2. T2

    Shade

    1.0 – 2.5

    Half-formed humanoid in a charcoal cloak. The decay begins to take form — a polite warning.

  3. T3

    Wraith

    2.5 – 5.0

    Armored revenant with verdigris and oxblood. A working system carrying real debt.

  4. T4

    Revenant

    5.0 – 8.0

    Hulking cursed body, smoldering crimson cracks. Debt is bleeding into reliability.

  5. T5

    Calamity

    > 8.0

    Deity-class composite curse, environmental distortion. Reserved for budget conversations.

A T5 portrait is alarming by design. Dorian asks before publishing it to a shared dashboard.

The Bundle

What one invocation returns

Each summon delivers the same four artifacts. Skipping any of them is incomplete delivery.

I.

Severity Report

Per-category scores, total score, tier (T1–T5), and top findings — every item carries path:line evidence.

II.

Portrait Spec

Tier silhouette, the list of visible flaws, each flaw cited back to a specific debt finding. One flaw, one debt.

III.

AI Image Prompt

Model-agnostic positive / negative prompts and style anchors. Pass to any image model. ASCII fallback when none is wired up.

IV.

Restoration Roadmap

Phased refactor list — Banish → Bind → Restore. Every item names the flaw it removes, so the next snapshot visibly improves.

Recipes

Four ways to call Dorian

summon

Default. Full portrait + severity report + restoration roadmap.

evolve

Diff two snapshots. Show how the portrait changed across a quarter or a refactor effort.

audit

Score only — no image. Useful as a CI gate.

restore

Roadmap only, derived from an existing portrait spec.

Installation

One folder. Drop it in.

Dorian is a self-contained Claude Code skill. Clone it into your skills directory, restart Claude Code, and summon the portrait by name.

  • “Dorian, summon a portrait of this repo.”
  • “Run dorian audit against the current branch.”
  • “Use Dorian to compare main vs this PR.”

Design Principles

The mirror, not the trophy

  • Detect honestly. No flaw on the portrait without path:line evidence behind it.
  • Score before styling. The tier comes from a formula, never a gut feel.
  • One flaw = one debt. Strict 1:1 mapping is what makes Dorian a diagnostic, not decorative AI art.
  • Restoration is the goal. The portrait is a mirror; the roadmap is the point.
  • Mythic, not comedic. Tone is gothic-serious. Humor undercuts the call to refactor.
